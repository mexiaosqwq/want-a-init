# want-a-init

DSH plugin that provides a model-driven `/init` command.

## Project

- Type: DeepSeek Harness host plugin (command only, no client).
- Language: plain ESM JavaScript; no build step required.
- Entry: `lib/index.js` exports `name`, `inject`, and `apply`.

## Commands

- Build/check: `bash scripts/build.sh` (no-op; verifies `lib/` exists)
- Syntax check: `node --check lib/index.js`

## Conventions

- Only `AGENTS.md` is generated by `/init`; never create `CLAUDE.md`.
- Keep the injected prompt high-signal: exact commands, real architecture, repo-specific pitfalls.
- Support `force`, `minimal`, and `detailed` modes.
